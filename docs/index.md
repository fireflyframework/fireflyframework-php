# LaraFly

**LaraFly** is the PHP edition of the Firefly Framework — Spring Boot's cohesion, native to Laravel 13.
It layers dependency injection with stereotypes, conditional auto-configuration, hexagonal ports &
adapters, CQRS, event-driven architecture, and a project CLI on top of Laravel's runtime.

> This site grows one module page per package as the Foundation cycle lands. Start with
> [Error Handling](modules/error-handling.md) — the `firefly/kernel` error model that everything builds on.
