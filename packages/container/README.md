# firefly/container

LaraFly's dependency-injection layer over `Illuminate\Container`: PHP 8 attribute stereotypes
(`#[Service]`, `#[Repository]`, `#[Configuration]` + `#[Bean]`), a PSR-4 component scanner compiled to a
cached manifest, interface auto-binding, `#[Primary]`/`#[Order]`/`#[Qualifier]`/`#[Lazy]` semantics, bean
scopes, and `#[Value]` config/expression injection.
